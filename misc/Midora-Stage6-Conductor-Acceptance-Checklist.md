## 建议顺序

| Check | 操作 | 预期 |
| --- | --- | --- |
| 01 | 新建项目，打开 Conductor | 左侧事件列表；右上 Tempo 图，右下拍号、调号、Marker、Project End。没有原底部列表重复占位 |
| 02 | 拖动左右分隔条、Tempo/Meta 分隔条；切换其他 Tab 再回来 | 可以双向调整且保持最小可用大小；宽度、左右图比例、列表滚动位置与 BPM 轴在当前工作区内保留 |
| 03 | 在 Tempo 图创建几个不同 BPM 的点 | 水平保持到下一个点，再垂直跳变；不能出现连接两点的斜线。两图相同 tick 的横坐标一致 |
| 04 | 平移到某个 Tempo 点之后，并将该点移出左边界 | 左界仍展示其有效保持值；不能回到默认 BPM 或失去保持线 |
| 05 | Draw 左键自由线、右键直线、Shift+右键水平线；分别开/关 Snap | 开 Snap 按选择的间距产生离散 Tempo；关 Snap 逐 tick；水平线保持起点 BPM，不是连续 ramp |
| 06 | 普通移动 Tempo、Shift 拖动、Ctrl 复制拖动、Select 框选和浮动 Move | Shift 固定 tick 只改 BPM；复制选择幸存副本。直接手势与浮动工具一致，显示 delta；右键双击仍按 300 ms 切换 Draw/Select |
| 07 | 将非初始 Tempo、拍号或调号移到已有同类事件的 tick | 后来编辑者覆盖旧值；撤销恢复两者及原选择。Marker 在同 tick 可以并存，包括同名和空名 |
| 08 | 改 tick 0 Tempo/拍号的值，再尝试移动/删除初始状态；输入非法 BPM | 原位改值成功；移动或删除必需初始状态被拒绝且无部分修改；BPM 必须为正且可表示为 MIDI Tempo，显示轴不改变此规则 |
| 09 | 使用 Fit、Axis…，鼠标滚轮缩放/平移 BPM 轴 | 只改变显示范围，不改 Project、不进入 Undo；高低 BPM 可通过 Fit/Axis 查看，非法轴输入不崩溃 |
| 10 | 在其他四条 Meta lane 上创建、移动事件；双击或右键 Properties | 显示对应类型的固定尺寸点和稀疏文字；只能在自身类型内移动。Properties 使用 OK/Cancel 原子提交，End 仍为单例 |
| 11 | 左侧单选、Ctrl 多选、Shift 范围、拖动范围；拖出上下边界 | 时间线选择同步；列表按绝对 tick、类型、稳定顺序显示。拖出边界可自动滚动；Escape 或丢失捕获取消拖动 |
| 12 | 右侧选择后观察左侧可见行；列表双击已多选中的某一行；使用 Locate | 高亮一致；双击只打开该行的属性。Locate 定位到该事件时间，不被过期后台结果改回旧位置 |
| 13 | 从列表或图形执行 Copy/Cut/Paste/Delete、Ctrl+A，再 Undo/Redo | 使用同一正式选择；Ctrl+A 包含全部 Conductor 类型。受保护 tick 0 与 End 单例限制仍生效，非法操作不部分完成 |
| 14 | 在密集 Tempo/Marker 的项目中快速平移、缩放、连续点击冷区域 | UI 不同步遍历百万事件；可见点尺寸不随缩放改变，密集点以列包络呈现；选区仍红色可辨，不丢正式事件 |
| 15 | 进行较大绘线/移动任务，取消；随后再次操作、撤销和重做 | 有真实进度/处理数，取消后原内容、选择与历史不受影响；成功一次手势对应一次 Undo |
| 16 | 冷区点击尚未完成时再次点击、改变缩放/轴、切换 Tab、关闭项目 | 旧请求不重放到新位置，不重新选回旧对象，不留下忙指针或后台旧工作区回写 |
| 17 | 保存、重开，编译、从中途播放、导出 MIDI | 五种正式事件保持；Tempo 仍离散，起点状态恢复/同 tick 排序不变；没有新增 Project Format 或音乐语义 |
| 18 | 简短回归 Arrangement 和三种钢琴卷帘的已有操作 | Arrangement Marker/概览正常；三种钢琴卷帘 Note、Velocity、Event 的显示、移动、缩放、选择和 Undo 不倒退 |

## 说明

- 密集图形是可视化聚合，不是删除 Tempo/Marker；完整事件可在列表中检查。
- 大任务的“准备”与“发布”分开。取消在准备阶段生效；原子发布开始后不能留下半个修改。
- 当前显示轴默认 0～240 BPM；0 是坐标下界而非合法 Tempo。绘制非法值会明确拒绝整次编辑，不默默钳制音乐内容。
- 自动性能数据的样本、范围和局限见同目录阶段 6 验证报告；不能把无窗口探针的内存峰值当作整个 Midora 的最低内存要求。
