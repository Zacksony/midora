## 1. 需求追踪与边界

| 维度 | 合同 |
|---|---|
| 输入 | Definition 模板长度与内容下界、冻结 Snap、Project 拍号图及 Segment 偏移、首次有效布局、实际编译任务进度。 |
| 输出 | 只有模板长度经正式原子命令改变音乐 source；标尺、Fit、进度是显示/运行期投影。 |
| 边界 | 模板不是可随意裁剪的 Segment；不得隐藏或删除内容来迎合手柄，不移动 Loop/Pre-Roll。低缩放抽样以全局序号为锚；整数 device pixel/key 至少3。 |
| 失败与反馈 | 无效 owner/revision、取消或失捕获不提交；下界饱和显示实际 delta；编译没有可靠 total 时显示阶段，不伪造百分比。 |
| 持久化 | 模板长度沿正式 source；Fit 的未来恢复值优先于初开默认；进度、拖动预览不保存、不进入 Undo。 |
| 非目标 | 不改变 Snap 单位、拍号/音乐时间语义、编译事件顺序、音频时钟；不为进度预先展开或扫描巨大编译结果。 |

实施前重读 SRS 第8、18、20章的模板/编辑边界，第11～13章的编译主线，以及第22章已批准的极端 Tick 算术不变量；按原需求文档的实际源码路径定位，不依赖历史行号。先补需求 trace，再同步正式规格中确需变更的 UI 合同。
