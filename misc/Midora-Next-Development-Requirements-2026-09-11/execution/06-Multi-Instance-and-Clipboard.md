# 多实例、持久音乐剪贴板与文件打开：执行边界

日期：2026-09-14。状态：**未开始；远期轮廓，安全门先于多实例功能曝光** 。

入口：[执行总计划](00-Execution-Plan.md)。需求／源码依据：[03](../03-Multi-Instance-and-Workspace-State.md)；唯一原答：[04](../04-Decisions-and-Preparation.md) D-MI01～06、D-OPEN01。本文件将C1/C3的大块任务拆开，不重开Q1/Q2，不承诺未经实测的协议吞吐。

## 1. 追踪与不扩大范围

| 维度 | 已定边界 |
|---|---|
| 需求／优先级 | R01=P2多阶段专题；R04=P3可独立做，之后接入多实例选窗 |
| 输入／输出 | 冻结源修订／选择→有界完整快照→同ProgramRoot持久当前槽→目标独立原子Paste；Stable ID重新分配，不按名称猜依赖 |
| 存储 | `<ProgramRoot>\Data\SharedClipboard`完整快照／current索引；`<ProgramRoot>\.tmp\SharedClipboard`未完成准备；同ProgramRoot、同用户共享，不在外部用户目录兜底 |
| 生命周期 | 仅一个持久当前槽，不做历史库；源退出／崩溃／Windows重启后完整兼容项仍可用；显式Clear或下次成功Copy/Cut替换 |
| 原子性 | 发布失败保旧槽；Cut只在可靠发布后删源，删源失败保源，不反向回滚全局已发布槽。目标Paste独立Undo，失败不反向Undo源Cut |
| 清理／升级 | 旧非当前快照待接收lease释放才回收；当前项不按年龄删；独立协议／数值契约／能力版本，兼容继续、不兼容明确拒绝、不自动删未知文件 |
| 同文件保护 | 一个项目文件一个可写会话；不同安装目录也不能绕过文件身份保护；保存检测外部修改，明确取消／Save Copy／确认备份后覆盖 |
| 非目标 | 不做跨目录／跨exe音乐剪贴板、云同步、历史素材库或自动恢复项目；文本框保持Windows文本剪贴板，外部文字Copy不改变音乐槽 |

正式最终范围仍含全部当前可复制对象：Note、适用Event/Parameter、Segment、Track、Definition、SubVoice及现有Mapping／曲线入口。首切片同TPQN基础对象不代表全部完成；复杂逻辑依赖仍限同TPQN，基础对象及适用Pure MIDI的跨TPQN按已确认比例与取整处理。

现行SRS §3/16/20/21及INV-019/086/093/094仍是单实例与旧路径白名单；C1必须同步正式规格／并发ADR后才编码。不得仅删Mutex就暴露多实例。配置／缓存／Worker隔离虽非主动音频优化，仍是该功能必要正确性门。

## 5. 人工验收批次轮廓

本节未开始；正式实施到对应阶段前再扩为精简的具体版本清单。已知批次无需每个内部子任务都验收。

- [ ] UAT-C2-01：打开两个项目窗口，同TPQN复制音符/事件至另一窗口；目标碰撞与选中结果正确，两窗口Undo分别作用于自身。
