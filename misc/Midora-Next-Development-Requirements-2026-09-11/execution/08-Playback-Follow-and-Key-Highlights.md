# 连续跟随与播放琴键染色

日期：2026-09-14。状态：**未开始，性能实验先行** 。P3 R10/R11分别设工程门，不用其中一项成功推定另一项可用。未运行实验。

原需求及源码入口见 [01 §6](../01-Interaction-and-Display.md)；原答为 [04 的 D-VIS01.a～d、D-VIS02.a～f、D-VIS03](../04-Decisions-and-Preparation.md)，Q2范围扩展见 [05](../05-Decision-Summary-and-Q2-2026-09-14.md)。共同要求见 [执行总索引](00-Execution-Plan.md)。

## 1. 已确认合同

| 维度 | 连续跟随R10 | 琴键染色R11 |
|---|---|---|
| 范围 | MIDI/Logical Segment、All Tracks、Arrangement、Conductor五类。 | 仅两类Segment与All Tracks；不随R10扩展到另外两类。 |
| 输入 | 现有正式播放指针与viewport，不另造音频时钟。 | 当前视图实际显示来源的半开Gate；原始/混合Compiled沿各自已有投影，不追踪BASS sample voice或release。 |
| 输出 | 全局关闭→跳跃→连续三态，默认关闭；锚点0～100%，默认0%，靠左/居中快捷值。 | 每Key来源色显示；当前编辑轨道优先，其余按洋葱皮最上层，All Tracks按后轨优先；不按Mute/Solo过滤。 |
| 边界 | 不显示负Tick；起点不足锚点距离时指针先移动到锚点。水平缩放保持Follow，以播放指针锚点处理。 | 精确Gate起止；Buffering冻结、Stop清空，Seek/Loop按新tick更新；不读屏幕bitmap推断音乐状态。 |
| 手动交互 | 中键/概览拖动期间临时暂停，松开或失捕获立即恢复；不关闭Follow；概览滚轮横移仍禁用。 | 用户选择/预览与缓存冷暖不改变正式来源判断；不可把装饰颜色当发声事实。 |
| 持久化 | 三态和锚点进入Application Preferences，不进入音乐Undo/canonical。 | 提供开关，性能通过后默认开启；具体偏好字段接现有应用设置合同。 |
| 退路 | 其他已有Follow但无连续能力的视图采用原跳跃，保留全局选择；本批五类不能借此静默遗漏。SubVoice不自动新增Follow。 | 性能优化仍不合格则暂缓，不私自换成近似像素染色。 |

共同非目标：不改变音频调度/Worker、不改变音乐内容或缓存身份、不新增播放编辑能力。实施前重读SRS §18.11及第22章渲染/消费者不变量；需要更新的已批准显示合同在正式切片同步。

## 4. 阻塞条件

- 冷区渲染、边界进出、选择层或编辑时延出现回退：不能靠“连续本来更重”自动接受，应定位后重测。
- 需要放松Gate精度或改已批准五类范围：回04提出具体新问题，不作为实现自由裁量。
- 用户已允许性能不合格时暂缓；没有测试证据不能将暂缓写成成功，也不预先承诺性能百分比。
