# 原生窗口、菜单图标、快捷键与后置动效

日期：2026-09-14。状态：**未开始，部分等待资料/发布条件** 。本文件集中低优先级外观与入口主题，内部相互独立；不是一个必须全做完的大交付包。

范围：P3 R03/R08/R09、P4 R02。依据 [01 §6](../01-Interaction-and-Display.md)、[04 的 D-WIN01、ENV-WIN10、D-KEY01/02、D-FX01.a～e](../04-Decisions-and-Preparation.md) 及 [执行总索引](00-Execution-Plan.md)。不包含图标选择问卷。

## 1. 边界与需求追踪

| 主题 | 已确认 | 非目标/进入条件 |
|---|---|---|
| R03原生窗口 | Win11原生圆角/阴影，Win10方角/阴影；遵守系统动画设置；不可用回退可靠现有行为。 | 可暂缓或不做。用户只能提供Win10虚拟机，不能写实机已验证；不为效果破坏Chrome命中、最大化工作区或DPI。 |
| R08菜单图标 | 未指定部分等用户逐项准备；已批准D-UI01.a/D-UI04局部图标照常随A3交付。 | 不代用户补全未选图标，不以R08等待阻塞已选局部入口。 |
| R09快捷键 | 可给新增/以前无键位的高频命令补键；保持现有键，不必覆盖全部低频操作。 | 不做可配置改键系统、不暗中重新绑定旧键。新增键位需源码冲突检查，菜单/Help与命令能力一致。 |
| R02动效 | 正式发布且稳定后；轻量短过渡，动画总关闭；亚克力独立默认关、首次内容就绪动效独立默认开。 | 系统减少动画/总关闭优先；性能不合格回退静态不透明。不能为播完动画延迟对象显示。 |

输出归属为UI或Application Preferences，不写音乐source/canonical。失败要能回到静态可靠UI，不部分改业务命令。正式切片重读SRS第17～20章及既有Style Gallery视觉基线，复用主题/控件模板，不另造主题分叉。
