=====loop bug=====

有一个必须阻塞并立即修复的BUG。是关于事件乐器loop的BUG。

【事件乐器配置】
· TEMPLATE LENGTH TICKS = 768
· LOOP START TICK = 192
· LOOP END TICK = 384
· 一个SubVoice，里面是：
  Tick 0, Note, Key 60, Gate 768, Vel 100;
  Tick 192, PitchBend, Value -7701;
  Tick 288, PitchBend, Value 8191
· ROOT NOTE = 60
· PRE-ROLL TICKS = 0
· Per-Note Instance Isolation = true
· Short Note = CutAtNoteOff
· Long Note = HoldLastState

【复现步骤与现象】
· 绑了上述事件乐器的逻辑轨道上，建了一个足够长的 Segment。
· 在此 Segment 里，Tick 0 处建了一个 Key 60, Gate 384, Vel 100 的 Note。
· 播放，正常正好播放到第一次 LOOP END TICK 的位置，也听出两次 PitchBend 正常生效。
· 将该 Note 的 Gate 加大至 576 Ticks。
· 播放，预期是应在 384 Tick 开始，再次重复一次那两个 PitchBend，但实际没有，这是BUG。
